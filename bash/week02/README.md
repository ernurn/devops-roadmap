## Key Concepts Learned

The main goal of week 2 was to move from individual Bash commands toward structured scripts.

The exercises introduced:

- Reusable functions
- Exit status handling
- Iteration
- User input
- Conditional logic
- Interactive menus
- Indexed arrays
- Associative arrays
- Safe parameter and array expansion

All exercises were developed and tested diretly on Ubuntu Server 24.04 LTS using Bash and Vim.
