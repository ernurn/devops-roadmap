## Learning Rules

- Study approximately one hour per day.
- Write every script manually.
- Use Vim as the primary editor.
- Use Git during every study session.
- Learn by building practical projects.
- Read `man` pages and built-in `help` before searching online.
- Investigate problems before asking for help.
- Understand commands instead of blindly copying and pasting.
- Document what you learn and verify your results.
